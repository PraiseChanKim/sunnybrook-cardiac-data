# 프로젝트 기준 (Term Project 안내문 요약)

> 원문: 초급프로젝트 PBL 1분반 Term Project 안내문 (수업 공지 첨부 PDF).
> 세부 구현 기준, 보고서 필수 항목, 평가 기준은 원문을 우선한다.

## 과제 개요
팀별로 영상처리 기능을 갖춘 **교육용 웹 PACS**를 구현한다.

| 항목 | 내용 |
|---|---|
| 제출 마감 | 2026-12-18 23:59 (한국 시간) |
| 시연 영상 | 팀 전체 3~5분 |

## 구현 요구사항
- 영상 저장 · 검색 · 조회, 이미지 뷰어, 검토 기록과 이력 관리
- 영상처리 알고리즘 **3종 이상**, ROI 분석, 팀별 특화 기능 **1개 이상**
- Python · Streamlit으로 개발하고 **JCloud에 배포**
- 로그인: **Firebase Authentication** / DB: **Cloud Firestore**

## Git 협업과 개인 역할
- 모든 팀원이 **직접 구현과 코드리뷰**에 참여해야 한다.
- 보고서에는 개인별 담당 기능, 코드 위치, Issue · 커밋 · PR 등 기여 근거를 작성한다.
- 같은 팀이라도 실제 기여와 이해도에 따라 개인 평가가 달라질 수 있다.
- 기여 근거가 남도록 작업은 Issue → 브랜치 → PR → 리뷰 순서로 진행하고, `docs/history/history-<이름>.md`에도 기록한다.

## 제출 방법 (팀원 모두 제출)
- **온라인 작성란**: 본인 · 팀원 정보, GitHub 저장소 주소와 최종 커밋 SHA, JCloud 배포 주소 · 테스트 계정, 시연 영상 링크
- **파일 제출란**: 팀 공통 보고서 PDF (개인별 기여 내용 필수)

## 우리 팀 주제
Sunnybrook Cardiac Data(심장 cine MRI)로 **심장 박동 cine 플레이어** 구현.
최소 범위는 시간축 재생, 프레임 선택, 좌심실 윤곽 오버레이이며, 선택 확장으로 수축/이완 면적 비교와 심실 용적 계산이 있다.
완료 확인은 프레임 정렬, 실제 contour와 오버레이 정합으로 한다. (출처: 수업 제공 「DICOM 공개 데이터셋 50선」 데이터셋 26)

## 구현 시 참고사항 (데이터셋 자료 기준)
- 순서: 영상 로딩과 기본 뷰어 → 주석/측정 → 결과 저장 → (선택) AI 추론
- 픽셀 표시: MONOCHROME1 반전, RescaleSlope/Intercept, windowing, PixelSpacing 처리
- 3D 시리즈 정렬은 파일명 대신 ImagePositionPatient / ImageOrientationPatient 사용
- 서로 다른 modality를 같은 좌표로 가정하지 않는다.
- 교육용이며 실제 진단용이 아니다.
